# Yet Another LLM Node

This is a custom node for the ComfyUI project, that interfacing with OpenAI compatabile API models. 

The intension to implement yet another one is that I need some simple yet tunable nodes in ComfyUI to generate or edit prompts. However the existing LLM nodes are either too complex or too simple for my use case.

## Features

- Support OpenAI API models
- Allow to chain multiple nodes to create multi-turn conversation.
